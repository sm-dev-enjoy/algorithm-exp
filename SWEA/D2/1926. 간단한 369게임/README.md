# [D2] 간단한 369게임 - 1926

### 문제 설명

<p>3 6 9 게임을 프로그램으로 제작하려 한다. 게임의 규칙은 다음과 같다.</p>

<p>1. 숫자 1부터 순서대로 차례대로 말하되 “3” “6” “9” 가 들어가 있는 수는 말하지 않는 대신, 박수를 친다. 그 외의 수는 그대로 이야기한다.</p>

<p>2. 박수는 한번 칠 수도 있고 연속 두 번 칠 수도 있다. 각 자리수마다 3, 6, 9가 들어간 개수만큼 박수를 친다. 예를 들어 33이나 36 등은 박수를 두 번 치게 된다.</p>

<p>박수 치는 부분은 글자 대신 “-” 문자를 출력한다. 33의 경우 “--” 가 된다.</p>

<p>정수 N이 주어졌을 때, 1부터 N까지의 숫자를 게임 규칙에 맞게 출력하는 프로그램을 작성하라.</p>
