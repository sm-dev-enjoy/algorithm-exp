### 문제 설명

<p>ROR 게임즈는 개발 중인 새로운 전략 게임의 미니 버전을 만들었습니다. 게임 맵의 크기는 n x m 크기의 격자 모양이며, 각 칸은 이동할 수 있는 길(1)과 이동할 수 없는 벽(0)으로 이루어져 있습니다. 캐릭터는 처음에 (1, 1) 위치에 있으며, 상대방 진영인 (n, m) 위치에 최대한 빨리 도달해야 합니다.</p>

<p>게임 맵의 상태 maps가 매개변수로 주어질 때, 캐릭터가 상대 팀 진영에 도착하기 위해 지나가야 하는 칸의 개수의 최솟값을 return 하도록 solution 함수를 완성해주세요. 단, 상대 팀 진영에 도착할 수 없을 때는 -1을 return 해주세요.</p>
